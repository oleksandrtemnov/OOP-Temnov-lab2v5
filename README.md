Висновок:

Під час виконання лабораторної роботи №2 досліджено повний життєвий цикл об’єкта в середовищі .NET framework:
Ініціалізація: Об’єкт створюється у керованій купі (Heap) за допомогою оператора new. При цьому викликається один із перевантажених конструкторів, який проводить початкову валідацію даних через властивості set.
Функціонування: Об’єкт залишається "живим" та доступним для виконання методів доти, доки на нього існує хоча б одне активне посилання.
Утилізація: Після присвоєння посиланням значення null об’єкт стає недосяжним. Примусовий виклик збирача сміття (GC.Collect()) запускає процес очищення пам'яті, під час якого виконується фіналізатор (~City()) для звільнення ресурсів.
